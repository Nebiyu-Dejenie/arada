# ADR-027: Delivery follows the Permanent Command phase order

| Field | Value |
|---|---|
| **Status** | Accepted — Permanent Command §55 |
| **Date** | 2026-09-26 |

## Decision
Phases: 0 Discovery, 1 Foundation, 2 Telegram, 3 Commerce core, 4 Payment + finance, 5 Reference vertical, 6 Merchant Factory, 7 Vertical expansion, 8 Advanced platform, 9 Scale.

## Context
The Master Directive's 0–15 order is superseded.

## Alternatives
The Master Directive §91 order.

## Reason
Proves one production-grade vertical before automating the factory, avoiding 18 weak verticals.

## Consequences
Before Phase 6, tenants are created through the same provisioning service using a CLI or admin endpoint, with no hand-built tenants.
